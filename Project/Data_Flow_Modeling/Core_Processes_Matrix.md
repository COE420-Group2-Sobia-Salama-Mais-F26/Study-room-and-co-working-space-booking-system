# Core Processes Matrix

The processes below are the same five major processes shown in the [Level-0 DFD](Level_0_DFD/README.md).

| Process No. and Name | Input Data | Output Data | Rules |
|---|---|---|---|
| **P1 – User Management** | Registration Information, Login Information, Profile Information, Booking History Request | Registration Confirmation, Login Confirmation, Profile Information, Booking History | The system shall validate registration information before creating an account. Users must provide valid login credentials to access their accounts. Profile information can only be updated by the corresponding user. Booking history shall only be displayed for the authenticated user. |
| **P2 – Space Search and Selection** | Search Criteria, Facility Filters, Space Details Request | Available Spaces, Space Details, Facility Information, Location Information, Availability Information | The system shall search spaces based on space type, location, date, time, duration, and capacity. Filters shall narrow results according to available facilities such as Wi-Fi, power outlets, whiteboards, and projectors. Only spaces matching the requested criteria and availability should be displayed. |
| **P3 – Booking Management** | Booking Request, Group Booking Information, Booking Modification Request, Booking Cancellation Request, Booking History Request | Booking Confirmation, Updated Booking Information, Cancellation Confirmation, Upcoming Booking Information, Previous Booking Information | A user can book only an available space. The system shall prevent overlapping bookings for the same space and selected time period. Modifications shall only be accepted when the new option is available. Cancellation shall update the space's availability. |
| **P4 – Availability and Notifications** | Availability Request, Space Status Request, Availability Update, Booking Information Request | Availability Information, Space Status, Availability Notification, Booking Reminder, Booking Notification | The system shall display the current availability status of spaces. Availability shall be updated when bookings are made, modified, cancelled, or when a space becomes available. Booking reminders and notifications shall be sent for relevant upcoming bookings and availability events. |
| **P5 – Administration** | User Management Request, Space Management Information, Availability Management Information, Reservation Management Request, Room Status Request, Report Request | User Information, Space Information, Availability Information, Reservation Information, Room Status, Booking Reports, Usage Reports, Management Confirmation | Only authorized administrators can manage users, spaces, availability, and reservations. Space information must include relevant details such as capacity and facilities. Administrators can generate booking and usage reports based on stored system data. |
