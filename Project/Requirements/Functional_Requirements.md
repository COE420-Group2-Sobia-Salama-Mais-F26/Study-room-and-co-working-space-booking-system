| FR-01 | The system shall allow users to search for meeting rooms and day-pass desks by city, date, start time, duration, and number of seats. Virtual offices shall be shown as listing only, because they cannot be booked through DeskOS | Space Search / Use | S-01 / UC-01 | Sobia adnan- g00100257 |
| FR-02 | The system shall allow users to filter spaces based on facilities such as Wi-Fi, power outlets, whiteboards, and projectors, where the DeskOS inventory provides facility data. The system shall display the status DeskOS returns: confirmed, or pending_approval when the operator approves bookings manually. | Booking Management / User | S-01 / UC-04 | Sobia adnan- g00100257 |
| FR-05 | The system shall allow customers to cancel an existing booking up to one hour before its scheduled start time (platform rule).
