# Functional Requirements

## Sobia Adnan – g00100257

**FR-01:** The system shall allow users to search for study rooms, private rooms, desks, and co-working spaces based on location, date, time, duration, and capacity.

**FR-02:** The system shall allow users to filter spaces based on facilities such as Wi-Fi, power outlets, whiteboards, and projectors.

**FR-03:** The system shall allow users to view space details, facilities, and location before selecting a space.

**FR-04:** The system shall allow users to make a booking for an available study room or co-working space.

**FR-05:** The system shall allow users to cancel an existing booking and update the availability of the space.

## Salama Alsuwaidi – g00099875

**FR-06:** The system shall allow users to modify an existing booking by changing the time, date, or room location.

**FR-07:** The system shall send user reminders before their scheduled booking time.

**FR-08:** The system shall notify users when a previously occupied space becomes available.

**FR-09:** The system shall allow administrators to add new study rooms and update existing room details, including capacity, facilities, and available times.

**FR-10:** The system shall allow users to create and update their profiles and view their booking history.

## Mais Abudaqqa – g00099729

**FR-11:** The system shall allow users to register for a new account using their name, email address, and password.

**FR-12:** The system shall prevent users from booking a space that is already reserved for the selected date and time.

**FR-13:** The system shall allow users to view their upcoming and previous bookings, including the space, date, time, and booking status.

**FR-14:** The system shall allow administrators to manage reservations by viewing, updating, or cancelling bookings when necessary.

**FR-15:** The system shall allow administrators to generate reports showing booking and space usage information.
