# Exercise 3: Identify Components and Distribute Project Classes

## Class Distribution

| ID | Component Name | Responsibilities | Included Classes |
|---|---|---|---|
| CO1 | Web Presentation Component | User interface for users and administrators | None (UI pages only; Lab 5 has no UI classes) |
| CO2 | Space Search Component | Search, filter and validate spaces | SpaceSearchService, SearchCriteria |
| CO3 | Booking Management Component | Booking creation, cancellation, modification and status updates | BookingService |
| CO4 | DeskOS Integration Component | Communication with DeskOS and callback handling | DeskOSAPI |
| CO5 | Account & Notification Component | Accounts, administration, notifications | User, PlatformAdmin, AvailabilityNotificationRequest, Notification |
| CO6 | Platform Data Component | Storage and retrieval of platform data | Space, Location, Facility, SpaceProvider, Booking, Availability |
