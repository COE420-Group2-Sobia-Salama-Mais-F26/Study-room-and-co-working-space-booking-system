## Main Changes

- Removed userId and spaceId from Booking, Availability, AvailabilityNotificationRequest and Notification, because these links are shown as associations instead.
- Marked DeskOSAPI as an external system.
- The administrator only manages the platform and does not edit external spaces.
- Removed the Report class. Reports are generated by PlatformAdmin.
