# 3.1. Work Breakdown Structure (WBS)

The WBS divides the project into 11 activities based on the actual work
needed to build the system. Durations are in days.

| **ID** | **Task Name**                                  | **Description**                                                                                                                                                                                                                                                                             | **Predecessors** | **Duration (Days)** |
|--------|------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------|---------------------|
| T1     | Requirements Refinement                        | Review and finalize the project scope, scenarios, functional and non-functional requirements, actors, and use cases from Labs 1–3, resolve inconsistencies before implementation.                                                                                                           | —                | 3                   |
| T2     | Database Design                                | Design the data stores shown in the Level-0 DFD (D1 User Data, D2 Space Data, D3 Booking Data, and D4 Notification Data), including the relationships between them.                                                                                                                         | T1               | 4                   |
| T3     | User Interface Design                          | Design interfaces for account registration, login, profile management, space search, filtering, space details, booking management, notifications, and administration.                                                                                                                       | T1               | 4                   |
| T4     | User Management Implementation                 | Implement account registration, authentication, login, profile management, user information, and access to booking history.                                                                                                                                                                 | T2, T3           | 5                   |
| T5     | Space Search and Selection Implementation      | Implement space searching and filtering by location, date, time, duration, capacity, space type, and facilities, implement space-detail viewing and the DeskOS API integration to retrieve cities, operators, campuses, spaces, and availability.                                           | T2, T3           | 6                   |
| T6     | Booking Management Implementation              | Implement booking creation and cancellation through the DeskOS API, booking confirmation, booking changes (book the new time slot, then cancel the old one), processing of booking-status callbacks, and viewing of upcoming and previous bookings.                                         | T4, T5           | 7                   |
| T7     | Availability and Notification Implementation   | Implement booking reminders, booking notifications, and availability alerts that regularly check availability from the DeskOS API and notify users when a previously unavailable space becomes available.                                                                                   | T6               | 5                   |
| T8     | Administration Implementation                  | Implement administrator functions for managing users, viewing and cancelling platform reservations, and generating booking and usage reports.                                                                                                                                               | T4, T5, T6       | 6                   |
| T9     | System Integration                             | Integrate user management, space search, booking management, availability and notification management, and administration, verify communication with the DeskOS API and ensure the components work together correctly.                                                                      | T7, T8           | 4                   |
| T10    | System Testing and Bug Fixing                  | Test registration, authentication, space search, filtering, external space information, booking operations, booking changes, cancellations, booking-status callbacks, availability checks, notifications, administration, data consistency, and system integration, fix identified defects. | T9               | 6                   |
| T11    | Deployment Preparation and Final Documentation | Prepare the system for deployment, finalize system documentation, verify the final functionality, and organize the project deliverables and repository.                                                                                                                                     | T10              | 3                   |
